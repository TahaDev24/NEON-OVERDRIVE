# Testing

## Manual smoke-check list

- [ ] Open the game in a current desktop browser.
- [ ] Start a run and verify the player appears.
- [ ] Move left and right.
- [ ] Jump from a platform.
- [ ] Collect a pickup and verify the counter changes.
- [ ] Hit an obstacle and verify the failure screen appears.
- [ ] Complete a zone and verify progression is saved.
- [ ] Reload the page and verify the saved counter/progression.
- [ ] Test touch controls on a mobile device.

This checklist is a test plan, not a claim that every item has been executed on every device.
